# OBS → HandBrake: автосжатие записей встреч

После остановки записи в OBS файл автоматически сжимается HandBrakeCLI и кладётся в `Видео\compressed`.
Оригинал остаётся на месте.

## Как подключить (один раз)
1. OBS → «Сервис» (Tools) → «Скрипты» (Scripts) → «+» → выбрать `obs-autocompress.lua` из этой папки.
2. Всё. Остановил запись → через несколько секунд сжатие стартует в фоне, по окончании всплывёт уведомление Windows.

## Что получается
- H.265 через Intel QuickSync (видеоядро, процессор почти не грузится), 15 к/с, звук AAC моно 64 кбит/с.
- Час встречи: было ~2,7 ГБ, станет порядка 30–100 МБ (зависит от того, сколько на экране движения).
- Пока OBS записывает, сжатие идёт на пониженном приоритете и медленнее. Без записи быстрее.
- Несколько записей подряд встают в очередь и сжимаются по одной.

## Настройки
В начале `compress.ps1`:
- `$Quality` — 24 по умолчанию. Мельче текст на экране → ставь 22; хочешь меньше файл → 28.
- `$DeleteOriginal = $true` — удалять исходник после успешного сжатия.
- `$OutDir` — куда класть результат.

## Сжать старые записи вручную
```powershell
powershell -ExecutionPolicy Bypass -File "C:\Slava Dev\obs-autocompress\compress.ps1" "C:\Users\Lenovo\Videos\запись1.mp4" "C:\Users\Lenovo\Videos\запись2.mp4"
```

## Если что-то не так
- `compress.log` — история: что сжато, сколько весило, сколько заняло.
- `handbrake-last.log` — подробный лог HandBrake по последнему файлу.
- `failed\` — записи, которые не сжались (путь внутри txt). Повторить: перенести txt обратно в `queue\` и запустить `compress.ps1` без параметров.
- При старте сжатия на долю секунды мелькает чёрное окно: это нормально, так OBS запускает фоновый процесс.
- HandBrakeCLI поставлен через winget (`HandBrake.HandBrake.CLI`). Обновить: `winget upgrade HandBrake.HandBrake.CLI`.

## Отправка в Whisperwise (ww.nextgensoft.co)
После сжатия всплывает окно поверх всех: проект, название, «Отправить» / «Нет, оставить себе». Без крестика, каждую минуту напоминает.
- Токен лежит в `whisperwise.config.json` (создаётся на ww.nextgensoft.co/account.html, в git не класть). Отозвать токен можно там же.
- Загрузка идёт на `POST /upload` с Bearer-токеном, список проектов — `GET /api/projects`.
- `upload.log` — что отправлено / отклонено / ошибки. `pending\` — вопросы без ответа, задаются снова при следующем сжатии.
- Окно можно вызвать вручную: `powershell -ExecutionPolicy Bypass -File ask-upload.ps1`.
- Гоча: процесс, запущенный с `-WindowStyle Hidden`, прячет и своё первое окно; в скрипте окно принудительно показывается (`Show-Front`).

## Первая настройка на новой машине
1. `winget install HandBrake.HandBrake.CLI` (нужен Intel QuickSync; иначе поменять кодек в `compress.ps1`).
2. Скопировать `whisperwise.config.example.json` в `whisperwise.config.json` и вписать свой токен (ww.nextgensoft.co/account.html). Файл в git не попадает.
3. Создать пустые папки `queue`, `failed`, `pending` (скрипты создают их сами при первом запуске, кроме `queue` для Lua — создать вручную).
4. Подключить `obs-autocompress.lua` в OBS (Сервис → Скрипты).

## macOS
На маке видео не пережимается: OBS пишет MKV (переживает краш), а для Whisperwise нужно только аудио.
После остановки записи `worker.sh` извлекает звук через `extract-audio` из этой папки (копия AAC-дорожки без перекодирования, секунды)
в `.m4a` рядом с записью и спрашивает про отправку. Час встречи ≈ 85 МБ (лимит сервера 500 МБ, видео целиком не пролезает).

Первая настройка:
1. `brew install ffmpeg` (PATH не важен, скрипт добавляет `/opt/homebrew/bin` сам).
2. Токен в Keychain (не в файл): `security add-generic-password -U -s whisperwise -a "$USER" -w 'ТОКЕН'`.
3. OBS → Tools → Scripts → «+» → `obs-autocompress.lua`.

- Вопрос висит, пока не ответишь (Esc не закрывает), раз в минуту пищит и всплывает снова. Неотвеченное остаётся в `queue/` и спросится после перезагрузки при следующем запуске.
- `worker.log` — что извлечено / отправлено / ошибки. `failed/` — не извлеклось; повторить: `mv failed/*.txt queue/ && ./worker.sh`.
- Вручную: `./worker.sh ~/Movies/запись.mkv` (без аргументов — разобрать очередь).
