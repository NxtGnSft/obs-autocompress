# OBS → Whisperwise: автообработка записей встреч

После остановки записи в OBS `obs-autocompress.lua` ставит файл в очередь (`queue/`) и запускает фоновый обработчик,
который потом спрашивает, отправить ли запись в Whisperwise (ww.nextgensoft.co). Оригинал остаётся на месте.

| | Windows | macOS |
|---|---|---|
| Обработчик | `compress.ps1` + `ask-upload.ps1` | `worker.sh` |
| Что делает | пережимает видео HandBrakeCLI (QuickSync) → `Видео\compressed` | извлекает аудио `extract-audio` → `.m4a` рядом с записью |
| Токен | `whisperwise.config.json` | Keychain |
| Лог | `compress.log`, `upload.log` | `worker.log` |

Разделы ниже до «macOS» — про Windows.

## Как подключить (один раз)
1. OBS → «Сервис» (Tools) → «Скрипты» (Scripts) → «+» → выбрать `obs-autocompress.lua` из этой папки.
2. Всё. Остановил запись → через несколько секунд сжатие стартует в фоне, по окончании всплывёт уведомление Windows.

## Что получается
- H.265 через Intel QuickSync (видеоядро, процессор почти не грузится), 15 к/с, звук AAC моно 64 кбит/с.
- Час встречи: было ~2,7 ГБ, станет порядка 30–100 МБ (зависит от того, сколько на экране движения).
- Пока OBS записывает, сжатие идёт на пониженном приоритете и медленнее. Без записи быстрее.
- Несколько записей подряд встают в очередь и сжимаются по одной.

## Настройки
В начале `compress.ps1`:
- `$Quality` — 24 по умолчанию. Мельче текст на экране → ставь 22; хочешь меньше файл → 28.
- `$DeleteOriginal = $true` — удалять исходник после успешного сжатия.
- `$OutDir` — куда класть результат.

## Сжать старые записи вручную
```powershell
powershell -ExecutionPolicy Bypass -File compress.ps1 "$HOME\Videos\запись1.mp4" "$HOME\Videos\запись2.mp4"
```

## Если что-то не так
- `compress.log` — история: что сжато, сколько весило, сколько заняло.
- `handbrake-last.log` — подробный лог HandBrake по последнему файлу.
- `failed\` — записи, которые не сжались (путь внутри txt). Повторить: перенести txt обратно в `queue\` и запустить `compress.ps1` без параметров.
- При старте сжатия на долю секунды мелькает чёрное окно: это нормально, так OBS запускает фоновый процесс.
- HandBrakeCLI поставлен через winget (`HandBrake.HandBrake.CLI`). Обновить: `winget upgrade HandBrake.HandBrake.CLI`.

## Отправка в Whisperwise (ww.nextgensoft.co)
После сжатия всплывает окно поверх всех: проект, название, «Отправить» / «Нет, оставить себе». Без крестика, каждую минуту напоминает.
- Токен лежит в `whisperwise.config.json` (создаётся на ww.nextgensoft.co/account.html, в git не класть). Отозвать токен можно там же.
- Загрузка идёт на `POST /upload` с Bearer-токеном, список проектов — `GET /api/projects`.
- `upload.log` — что отправлено / отклонено / ошибки. `pending\` — вопросы без ответа, задаются снова при следующем сжатии.
- Окно можно вызвать вручную: `powershell -ExecutionPolicy Bypass -File ask-upload.ps1`.
- Гоча: процесс, запущенный с `-WindowStyle Hidden`, прячет и своё первое окно; в скрипте окно принудительно показывается (`Show-Front`).

## Первая настройка на новой машине
1. `winget install HandBrake.HandBrake.CLI` (нужен Intel QuickSync; иначе поменять кодек в `compress.ps1`).
2. Скопировать `whisperwise.config.example.json` в `whisperwise.config.json` и вписать свой токен (ww.nextgensoft.co/account.html). Файл в git не попадает.
3. Папки `queue`, `failed`, `pending` создаются сами при первом запуске.
4. Подключить `obs-autocompress.lua` в OBS (Сервис → Скрипты).

## macOS
Видео не пережимается: для Whisperwise нужно только аудио, а целиком видео не пролезает в лимит сервера (500 МБ).
`worker.sh` извлекает звук через `extract-audio` (копия AAC-дорожки без перекодирования, секунды) в `.m4a` рядом
с записью и спрашивает про отправку. Час встречи ≈ 85 МБ.

Первая настройка:
1. `brew install ffmpeg` (PATH не важен: OBS из Finder видит голый PATH, скрипт сам добавляет `/opt/homebrew/bin`).
2. OBS → Settings → Output → Recording: формат MKV (переживает краш, не нужен ретрай «файл ещё дописывается»),
   аудиокодек AAC (иначе `extract-audio` не сможет скопировать дорожку в `.m4a`).
3. Токен (создаётся на ww.nextgensoft.co/account.html, там же отзывается) — в Keychain, не в файл:
   `security add-generic-password -U -s whisperwise -a "$USER" -w 'ТОКЕН'`.
4. OBS → Tools → Scripts → «+» → `obs-autocompress.lua`.

Как это выглядит:
1. Окно «Отправить в Whisperwise?» с названием (по умолчанию имя файла) → «Отправить» / «Нет, оставить себе».
2. После «Отправить» — список проектов (если проект один, шаг пропускается). «Cancel» возвращает к первому окну.
3. Загрузка, затем уведомление со ссылкой. Ошибка (сеть, токен, сервер) показывается в первом окне, можно повторить.

Мелочи:
- Esc окно не закрывает; без ответа раз в минуту пищит и всплывает снова. Неотвеченное остаётся в `queue/` и спросится при следующем запуске (переживает перезагрузку).
- Одновременно работает один обработчик (`.lock/`, зависший лок мёртвого процесса снимается сам); остальные ждут и разбирают очередь.
- `worker.log` — что извлечено / отправлено (со ссылкой) / ошибки и ответ сервера. `failed/` — не извлеклось; повторить: `mv failed/*.txt queue/ && ./worker.sh`.
- Вручную: `./worker.sh ~/Movies/запись.mkv` (или сразу `.m4a`; без аргументов — разобрать очередь).
  `./extract-audio` работает и сам по себе: без аргументов берёт последнюю запись из `~/Movies`.
- Гоча: на маке `/bin/bash` версии 3.2 — в строках с кириллицей писать `${var}`, а не `$var»`: байты кириллицы bash считает частью имени переменной (`unbound variable`).
- Гоча: не редактировать `worker.sh`, пока он висит с открытым окном — bash читает скрипт по ходу выполнения.
